# ConsoleSelenium42

Projeto acadêmico de automação de testes desenvolvido em C# utilizando Selenium WebDriver e MSTest.

## Tecnologias utilizadas

- C#
- .NET 10
- Selenium WebDriver
- Selenium Support
- MSTest
- Git e GitHub

## Exercícios desenvolvidos

### Exercício 1 — Pesquisa básica
- Acesso ao DuckDuckGo.
- Preenchimento do campo de pesquisa.
- Pesquisa por Selenium WebDriver C#.
- Validação da página de resultados.

### Exercício 2 — Autocompletar
- Preenchimento do campo de pesquisa.
- Espera explícita com WebDriverWait.
- Seleção da terceira sugestão.
- Validação da navegação.

### Exercício 3 — Navegação pelo histórico
- Pesquisa por Automated Testing.
- Abertura do primeiro resultado.
- Validação da página externa.
- Retorno utilizando o botão Voltar do navegador.
- Validação da restauração dos resultados.

## Como executar

Clone o repositório:

```bash
git clone https://github.com/alicefbarbosa/console-selenium-42-net.git
```

Entre na pasta:

```bash
cd ConsoleSelenium42
```

Execute os testes:

```bash
dotnet test
```
